# Modern Dashboard — Design System Instructions

`theme.css` এখন আপডেট হয়ে গেছে — কালার টোকেনের সাথে typography, spacing, radius টোকেনও যোগ হয়েছে। নিচে প্রতিটা এলিমেন্টের নিয়ম বাংলায় লেখা হলো, এজেন্টকে এটাও দিয়ে দাও।

## ১. Border Radius — কোথায় কতটুকু গোল

| এলিমেন্ট | Radius | Token |
|---|---|---|
| ইনপুট, ছোট বাটন, ব্যাজ | 8px | `--radius-sm` |
| বড় বাটন, টেবিল সেল, ড্রপডাউন | 12px | `--radius-md` |
| কার্ড, প্যানেল | 16px | `--radius-lg` |
| মোডাল, বড় হিরো প্যানেল | 20px | `--radius-xl` |
| পিল/ট্যাগ, অ্যাভাটার, প্রোগ্রেস বার | 999px (ফুল গোল) | `--radius-full` |

**নিয়ম**: একই স্ক্রিনে radius যতটা সম্ভব ১-২ ধাপের বেশি বৈচিত্র্য রাখবে না (যেমন কার্ডে lg + ভেতরের বাটনে sm — এই দুইটাই ঠিক আছে), কিন্তু র‍্যান্ডম ভ্যালু (যেমন 6px, 10px, 14px মিশিয়ে) ব্যবহার করবে না।

## ২. Background — লেয়ার অনুযায়ী

- **পেজ ব্যাকগ্রাউন্ড**: `--bg-page` (`#F6F4F9`) — খাঁটি সাদা না, হালকা বেগুনি আভা যুক্ত ধূসর। এটাই ডেপথ তৈরি করে।
- **কার্ড/সারফেস**: `--bg-surface` (সাদা) — পেজ bg-র চেয়ে হালকা হওয়ায় "উপরে ভাসছে" এমন ফিল আসে।
- **ইনপুট ফিল্ড**: ডিফল্টে হালকা ধূসর fill (`--neutral-200`), focus হলে সাদা হয়ে বর্ডার বেগুনি হয়ে যায় — এটা মডার্ন প্যাটার্ন (Linear/Notion স্টাইল)।
- শ্যাডো কখনো খাঁটি কালো (`rgba(0,0,0,...)`) ব্যবহার করবে না — এই সিস্টেমে বেগুনি-টিন্টেড শ্যাডো (`--shadow-card`) ব্যবহার করা হয়েছে, এটাই সফট ও মডার্ন লুক দেয়।

## ৩. Font / Typography

- **Font family**: `Inter` (ইংরেজি/সংখ্যার জন্য) + `Hind Siliguri` (বাংলা টেক্সটের জন্য fallback) — `--font-sans` টোকেনে সেট করা আছে। Inter-এ বাংলা গ্লিফ নেই, তাই বাংলা UI টেক্সট থাকলে এই fallback জরুরি।
- **Font weight**:
  - বডি টেক্সট/প্যারাগ্রাফ → 400 (regular)
  - লেবেল, ন্যাভ আইটেম, টেবিল হেডার → 500 (medium)
  - হেডিং, বাটন টেক্সট, কার্ড টাইটেল → 600 (semibold)
  - শুধু পেজ টাইটেল আর KPI/স্ট্যাট নাম্বারে → 700 (bold) — bold খুব বেশি জায়গায় ব্যবহার করলে সবকিছু "চেঁচামেচি" করে দেখাবে
- **Font size স্কেল** (px):
  - পেজ টাইটেল (H1): 28px, bold
  - সেকশন/কার্ড হেডার (H2): 22px, semibold
  - সাব-হেডার (H3): 18px, semibold
  - বডি/টেবিল টেক্সট: 14px, regular — এটাই ড্যাশবোর্ডের ডিফল্ট সাইজ
  - ক্যাপশন/হেল্পার টেক্সট: 12-13px, medium
  - বড় KPI নাম্বার (যেমন "৳ ৪৫,০০০"): 28-34px, bold, `font-variant-numeric: tabular-nums` (সংখ্যা লাইন-আপ ঠিক থাকার জন্য)

## ৪. হেডার (Header/Navbar) স্টাইল

- ব্যাকগ্রাউন্ড: সাদা (`--bg-surface`), নিচে হালকা বর্ডার (`--border-default`) — শ্যাডো না দিয়ে শুধু হেয়ারলাইন বর্ডার দিলে বেশি ক্লিন লাগে
- পেজ টাইটেল: 22-28px, semibold/bold, `--text-primary`
- হেডারে একটাই accent এলিমেন্ট রাখবে (যেমন primary বাটন বা সার্চ), সবকিছু বেগুনি করে ফেলবে না
- Sticky হেডার হলে scroll করলে হালকা shadow (`--shadow-card`) যোগ হবে — এটা "elevation on scroll" প্যাটার্ন, মডার্ন লাগে

## ৫. কালার কম্বিনেশন — সংক্ষিপ্ত নিয়ম

- **প্রতি স্ক্রিনে একটাই dominant accent color** — `--purple-600`। এটা শুধু primary action, active state, আর একটা key metric-এ ব্যবহার করবে।
- **Background + Text সবসময় বিপরীত এন্ড থেকে নিবে**: হালকা bg (50/100) + গাঢ় text (700/800/900), বা গাঢ় bg (600+) + সাদা text। মাঝামাঝি দুইটা শেড কখনো একসাথে মেলাবে না — কনট্রাস্ট কমে readability নষ্ট হয়।
- **৮০/১০/১০ নিয়ম** মাথায় রাখো: ৮০% UI নিউট্রাল (সাদা/ধূসর/কালো টেক্সট), ১০% বেগুনি অ্যাকসেন্ট, ১০% সেমান্টিক কালার (success/warning/danger)। পুরো স্ক্রিন বেগুনি দিয়ে ভরিয়ে ফেললে ক্লান্তিকর লাগবে, প্রফেশনাল লাগবে না।

## ৬. এজেন্টকে বলার জন্য এক লাইনের যোগ করা ইন্সট্রাকশন

আগের প্রম্পটের সাথে এটাও জুড়ে দাও:

```
এখন theme.css এ typography, spacing, radius token যোগ হয়েছে
(--text-*, --weight-*, --space-*, --radius-*)। সব হেডিং, বাটন,
কার্ড, ইনপুটে এই টোকেন ব্যবহার করো, র‍্যান্ডম px ভ্যালু বসিও না।
DESIGN-SYSTEM.md ফাইলে বিস্তারিত নিয়ম আছে, সেটা অনুসরণ করো —
বিশেষ করে ৮০/১০/১০ কালার রুল এবং font-weight এর নিয়মগুলো।
```
