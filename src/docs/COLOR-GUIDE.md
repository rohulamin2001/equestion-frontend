# Purple Dashboard — Color System গাইড

তোমার আপলোড করা গ্রেডিয়েন্ট থেকে ৭টি রঙ এক্সট্র্যাক্ট করে (dark violet → magenta) একটা পূর্ণাঙ্গ **light-theme** color token সিস্টেম বানানো হয়েছে। এই ফাইল + `theme.css` — দুটোই AI এজেন্টকে দিয়ে দাও, ও সরাসরি অ্যাপ্লাই করতে পারবে।

## মূল পরিবর্তনযোগ্য ফাইল
- `theme.css` — সব CSS variable + রেডি-মেড component class (button, card, input, sidebar, badge ইত্যাদি)

## ১. এক্সট্র্যাক্ট করা মূল প্যালেট

| Token | Hex | কোথায় ব্যবহার হবে |
|---|---|---|
| `--purple-900` | `#58085F` | সবচেয়ে গাঢ়। হেডিং টেক্সট, হাই-এম্ফাসিস কনটেন্ট, hero gradient-এর শুরু |
| `--purple-800` | `#720A7B` | Primary button-এর **active/pressed** state, icon chip-এর টেক্সট কালার |
| `--purple-700` | `#830D97` | Primary button-এর **hover** state, লিংক hover, active nav আইকন |
| `--purple-600` | `#900EB0` | **মূল ব্র্যান্ড কালার** — ডিফল্ট বাটন, লিংক, active/selected state, বর্ডার |
| `--purple-500` | `#B010CA` | সেকেন্ডারি অ্যাকসেন্ট — গ্রেডিয়েন্ট, চার্ট বার |
| `--purple-400` | `#D510E6` | ব্রাইট অ্যাকসেন্ট — progress bar, স্পিনার, **focus ring** কালার |
| `--purple-300` | `#E312F2` | সবচেয়ে উজ্জ্বল, শুধু ছোট ছোট এক্সেন্ট বা হাইলাইটে — বেশি জায়গায় ব্যবহার করলে চোখে ধকল লাগবে |
| `--purple-200`–`--purple-50` | হালকা টিন্ট | ব্যাকগ্রাউন্ড, hover bg, icon chip bg, selected row bg — মূল রঙগুলো থেকে সাদার সাথে মিশিয়ে বানানো, ছবিতে ছিল না |

## ২. কোথায় কোনটা ব্যবহার করবে (উত্তর তোমার প্রশ্নের)

- **Background (পেজ)**: `--neutral-100` (`#F6F4F9`) — হালকা ধূসর-বেগুনি আভা, খাঁটি সাদা না। কার্ড/সারফেস `--neutral-0` (সাদা)।
- **Hover**: বাটনে ১ ধাপ গাঢ় (600→700→800)। রো/মেনু আইটেমে হালকা টিন্ট ব্যাকগ্রাউন্ড (`--purple-50` বা `--purple-100`) — কখনো টেক্সট গাঢ় কালো করবে না।
- **Border**: ডিফল্ট বর্ডার নিউট্রাল ধূসর (`--neutral-300`), শুধু focus/active অবস্থায় বেগুনি বর্ডার (`--purple-600`)। সব বর্ডারে বেগুনি দিলে UI ভারী দেখাবে।
- **Outline / Focus ring**: `--purple-400` দিয়ে ৩px soft glow (`box-shadow: var(--focus-ring)`) — শক্ত ২px সলিড আউটলাইনের বদলে নরম গ্লো বেশি মডার্ন দেখায়। Accessibility-এর জন্য `:focus-visible` সবসময় রাখা হয়েছে।
- **Background chip/badge**: হালকা টিন্ট (`--purple-50`/`100`) + তার সাথে গাঢ় টেক্সট (`--purple-700`/`800`) — কখনো একই শেডের bg + text মেলাবে না, কনট্রাস্ট থাকা লাগবে।
- **টেক্সট**:
  - প্রাইমারি বডি টেক্সট: `--neutral-900` (প্রায়-কালো, খাঁটি কালো না — বেগুনির আভা আছে)
  - সেকেন্ডারি/মিউটেড টেক্সট: `--neutral-700` / `--neutral-500`
  - লিংক/অ্যাকশন টেক্সট: `--purple-700`
  - বাটনের ভেতরের টেক্সট (বেগুনি bg-র উপর): সাদা (`#FFFFFF`)
- **Primary CTA বাটন**: bg `--purple-600`, hover `--purple-700`, active `--purple-800`, সাথে হালকা glow shadow (`--shadow-brand-glow`) — এটাই সবচেয়ে বেশি চোখে পড়বে এমন এলিমেন্ট, তাই পুরো পেজে খুব বেশি জায়গায় সলিড বেগুনি ব্যবহার না করে শুধু এই CTA-গুলোতে জোর দাও।
- **Sidebar active nav item**: সলিড `--purple-600` bg + সাদা টেক্সট; বাকি সব আইটেম transparent, hover এ হালকা টিন্ট।
- **Chart/গ্রাফ**: একাধিক সিরিজ থাকলে ৪টা ধাপ ব্যবহার করো (800→600→400→200) — একই ফ্যামিলির শেড হওয়ায় ভিজুয়ালি সামঞ্জস্যপূর্ণ লাগবে, আলাদা আলাদা রঙ মেশানোর দরকার নেই।

## ৩. যোগ করা নতুন রঙ (ছবিতে ছিল না, কিন্তু দরকার ছিল)

মূল ছবিটা শুধু বেগুনি-ম্যাজেন্টা মনোক্রোম শেড ছিল। একটা ইউজেবল ড্যাশবোর্ডের জন্য যা মিসিং ছিল তা যোগ করা হয়েছে:
- **নিউট্রাল ধূসর স্কেল** (`--neutral-*`) — টেক্সট, বর্ডার, পেজ ব্যাকগ্রাউন্ডের জন্য। শুধু বেগুনি দিয়ে টেক্সট/বর্ডার করলে কনট্রাস্ট ও রিডেবিলিটি খারাপ হয়ে যেত।
- **Success / Warning / Danger** কালার (সবুজ/হলুদ/লাল) — স্ট্যাটাস ব্যাজ, এরর মেসেজ, ভ্যালিডেশনের জন্য। এগুলো বেগুনি প্যালেটের সাথে না মিশিয়ে আলাদা, স্ট্যান্ডার্ড সেমান্টিক কালার হিসেবে রাখা হয়েছে যাতে ইউজার এগুলোকে আলাদাভাবে চিনতে পারে।

## ৪. এজেন্টকে যা বলবে

AI এজেন্টকে এই দুটো ফাইল দিয়ে বলতে পারো:
> "এই `theme.css`-এর CSS variable ও ক্লাসগুলো প্রজেক্টে import করো, hardcoded কোনো hex color ব্যবহার না করে সবজায়গায় `var(--token-name)` ব্যবহার করো। বাটন, কার্ড, ইনপুট, সাইডবার, ব্যাজের জন্য উপরের রেডি ক্লাসগুলো (`.btn-primary`, `.card`, `.input`, `.nav-item` ইত্যাদি) ডাইরেক্ট ব্যবহার করো।"

## ৫. নিয়ম যা মেনে চলা উচিত (Common mistakes এড়াতে)

- সব জায়গায় স্যাচুরেটেড বেগুনি (600+) ব্যবহার করবে না — শুধু primary action/emphasis-এ। বাকি জায়গায় নিউট্রাল বা হালকা টিন্ট।
- `--purple-300` (সবচেয়ে উজ্জ্বল) বড় ব্যাকগ্রাউন্ড এরিয়াতে ব্যবহার করবে না, শুধু ছোট অ্যাকসেন্টে।
- Bg color আর তার উপরের text color একই শেড-ফ্যামিলি থেকে নেবে কিন্তু বিপরীত এন্ডের (হালকা bg + গাঢ় text, বা গাঢ় bg + সাদা text) — কখনো মাঝামাঝি দুটো শেড মেলাবে না, কনট্রাস্ট কমে যাবে।
